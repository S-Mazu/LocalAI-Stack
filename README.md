# LocalAI-Stack

HowTos, docker-compose files and scripts for building your own local AI stack. Everything here is Proof of Concept and playground material for your own hardware.

Every sub-project below has its own `README.md` with the full setup — pick one and open its folder.

## Sub-projects

| Project | What it is |
|---|---|
| [`LocalAI-Stack/`](LocalAI-Stack/README.md) | A fully local RAG/tools chat stack — Ollama, Open WebUI, Docling, mcpo, n8n and Caddy on Windows/WSL2/Docker. |
| [`MTP-MultiTokenPrediction/`](MTP-MultiTokenPrediction/README.md) | A benchmark test stack comparing llama.cpp with Multi-Token Prediction against llama.cpp without it and against Ollama, using Gemma 4 12B. |
